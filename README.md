# privacy-ner-att
This project develops a NOVEL Language Model to detect privacy disclosures through paying attention to privacy sensitive entities in a Sentence through NER.

## Abstract

This repository contains code for privacy disclosures in text generated by a language model by paying attention to the named entities and their relations to PII sensitive tags in the generated text. 

## Description

We use a foundational model embeddings to start with and then
1. Layer  CRFNerHead or SoftMaxNerHead x 2
   These 2 heads train on ONTO Notes tagged input text. One is called as Personal NER Head that trains on
   tokens tagges with [B-PER], [I-PER] etc. The other is trained on PII sensitive tokens like [SSN], [B-HOSPITAL] etc.
   We use SoftMax and did Ablation studies using CRF to ensure ordering.
2. Layer CrossAttention Layer
The outputs of these heads and the Foundational Model is fed to this cross attention layer
The Q Vector is based only on the Personal NER Head output through appropriatedly computed Attention Mask
The K Vector is based on the PII NER Head, againg using proper Attention to tags
This ensures that the model focuses only on the Personal and PII tokens and all the [O] tokens are ignored for attention
4. PrivacyClassifier
The Result of the Cross Attention is fed to a Binary Classifier to outputs a binary probability score to predict if the input text contains privacy sensitive information about the person.
5. The Privacy Model wraps up all these elements and trains them and predicts.

## Setup

To set up the environment, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/pals-ucb/privacy-ner-att
   cd privacy-ner-att
   
   ```

2. Install dependencies:

   ```bash
   conda create --name prv_ner_att_tf_3_10 PYTHON=3.10
   conda activate prv_ner_att_tf_3_10
   pip install -r requirements.txt
   ```
